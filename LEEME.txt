HUELLAS VR · BABYLON.JS 9.37.2 / WEBGL 2

ESTADO ACTUAL
- Motor único: Babylon.js + WebGL 2. Física: Havok Physics V2.
- Destino: navegador web móvil y escritorio mediante HTTPS.
- Cinco mundos: Atacamatitan, Arackar, Gonkoken, Stegouros y Chilesaurus.
- Único perfil gráfico: EQUILIBRADO. No hay selector ni parámetros públicos de calidad alta/media/baja.
- WebXR immersive-vr se ofrece cuando navegador y visor son compatibles; también hay orientación móvil y modo estereoscópico.
- La carga funcional automatizada de los cinco mundos pasó en Chromium. Esto no certifica paridad visual, 60 FPS físicos ni visor real.

EJECUCIÓN
1. Publicar la carpeta en un servidor HTTPS y abrir index.html.
2. Elegir Explorar o Usar con visor VR.
3. Acceso directo por mundo: ?mundo=atacamatitan, ?mundo=arackar, ?mundo=patagonia, ?mundo=stegouros o ?mundo=aysen.
4. Diagnóstico: ?debug=1. Pruebas internas: ?test=1.
No usar ?q=: no existen perfiles alternativos seleccionables.

CONTROLES
- Escritorio: WASD/flechas y ratón.
- Móvil: arrastrar para mirar; tocar el terreno para caminar; tocar un dinosaurio para abrir su ficha.
- Visor móvil: botón de modo estereoscópico.
- WebXR: requiere HTTPS, navegador y visor compatibles.

DEPENDENCIAS LOCALES
- Babylon.js 9.37.2: vendor/babylon/babylon.js.
- Cargadores GLB: vendor/babylon/babylonjs.loaders.min.js.
- Havok 1.3.14: vendor/babylon/havok/HavokPhysics_umd.js y HavokPhysics.wasm.
- Motor, cargadores y Havok se sirven desde el repositorio, no desde CDN.
- Regenerar dependencias: npm install y npm run vendor:babylon.
- Licencias: vendor/babylon/licenses/.

ESTRUCTURA
vendor/babylon/ motor, cargadores, Havok y licencias.
img/ panoramas, texturas y mapas de altura.
models/ dinosaurios y entorno GLB.
css/ interfaz.
js/ lógica Babylon.js.
tests/ auditoría, navegador, estabilidad y rendimiento.
scripts/ empaquetado.

PRUEBAS
Requiere Node.js 22+: npm install; npx playwright install chromium; npm test.
La suite ejecuta auditoría estática, pruebas funcionales, visuales y rendimiento. SwiftShader es renderizado software y no certifica FPS de GPU física. Android, PC físico y visor WebXR requieren ensayos reales.

PERFIL GRÁFICO
La etiqueta pública es Equilibrado. El identificador interno heredado quality='media' se conserva por compatibilidad del código; no habilita otro perfil. Los parámetros están centralizados en js/main.js.
